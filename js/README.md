# Tienda-Rugby

Sitio web de indumentaria y accesorios de rugby, realizado como proyecto final de la materia Programación Web 1.

## Funciones

- **Página de inicio:** catálogo con 24 productos (pelotas, shorts, camisetas, bucales y tees) de las líneas Gilbert, Adidas, Canterbury, Flash y sin marca.
- **Panel de administrador:** permite agregar productos, ver el listado y eliminar productos. Los datos se guardan en el navegador con Local Storage.
- **Contacto:** botón flotante que abre un mail de consulta.
- **Diseño adaptable:** se ajusta a pantallas chicas.

## Tecnologías

- HTML
- CSS
- JavaScript (sin librerías)

## Estructura

```
Tienda-Rugby/
├── index.html      # Página de inicio con el catálogo
├── admin.html      # Panel de administrador
├── css/
│   └── styles.css
├── js/
│   └── app.js      # Lógica del administrador y Local Storage
└── img/            # Imágenes de los productos
```

## Cómo ejecutarlo

1. Clonar o descargar el repositorio.
2. Abrir `index.html` en el navegador (doble clic), o usar la extensión **Live Server** de VS Code.
3. Para administrar productos, entrar a **Administrador** desde el menú.
